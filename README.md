# Crypto Currency Android App

App name: Crypto Currency
Subtitle: From Beginner to Advanced Trading
Author: Muhammad Tukur

Features:
- 8 learning modules
- Hausa lesson content
- Search
- Progress tracking during the current app session
- Mark lesson as completed
- Dark mode
- Quiz-ready lesson structure
- Offline lesson content (no internet required for the included text)
- Risk disclaimer

Build:
flutter pub get
flutter build apk --release

APK output:
build/app/outputs/flutter-apk/app-release.apk

Note: This project is ready for an online/local Flutter build. The chat environment cannot directly publish a compiled APK to your phone.
